**Applies to:** Duty Manager, Bar Supervisor

**Restricted:** yes, authorized-tier only (Tech Bible §15i). Both closing-authorized roles get this, matching the venue's own existing rule that either can close alone (Closing Procedures, Section 1).

## Section 1: Setting and disarming the alarm

The alarm panel is just inside the office door, to the left of the light switch. Code: 7734.

To arm it at close, enter the code then press the lock symbol. You have 45 seconds to get out through the front door before it activates. To disarm it on arrival, enter the code then press the unlock symbol within 30 seconds of opening the front door, or it triggers a call from the monitoring company.

Marcus reviews this code every six months. If the panel ever shows a fault light, don't try to reset it yourself, call Merri Locksmiths' 24 hour line and let Marcus know.
